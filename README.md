# Sistema Jurídico

Sistema privado do escritório para gestão de clientes sindicais, associados, documentos, cálculos trabalhistas e petições.

- `calculadora/`: calculadora de rescisão CLT já em uso (HTML autocontido). Veja `calculadora/README.md`.
  Para gerar a página: `python3 calculadora/build.py` (sai em `calculadora/dist/`).
